Fish support

Practice Moroccan Darija while you walk. This page is for the Fish iOS / Mac app (com.devdarija.fish).

Get started

  1. Sign in with iCloud on the device so entries and media can sync.
  2. Open Settings → Import FISH.xlsx, then import your image and audio folders. The app ships empty on purpose.
  3. Or tap Library → + and add one English / Darija card by hand.
  4. Start Watcher, Listener, or Reader. If no cards match, open Session setup and enable the right levels (default: 300, 1000, 2000).

Help

  • Filenames: images 00014.jpg, English audio 01016E.mp3, Darija audio 01016D.mp3.
  • Optional Dropbox backup: Settings → choose a folder in Files. Fish copies a disaster-recovery folder about once a day. This is not a second live database.
  • Listener can keep playing with the screen locked (pocket drills).
